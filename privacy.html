Privacy Policy & Data Handling

Digital Memory Vault • Last updated: October 2026

1. Overview

Digital Memory Vault is a personal productivity and memory search tool. It allows users to connect their Google Account to search across their personal emails, files, photos, and calendar events from a single interface.

2. Google API Permissions & OAuth Scopes

When you connect your Google Account, Digital Memory Vault requests read-only OAuth scopes to execute user-initiated searches. The application uses the following Google API scopes:

Google API Scope Technical Purpose
https://www.googleapis.com/auth/gmail.readonly Queries Gmail message headers and snippets matching the user's search term.
https://www.googleapis.com/auth/drive.readonly Searches Google Drive file names, metadata, and thumbnails matching the user's search term.
https://www.googleapis.com/auth/photoslibrary.readonly
...photoslibrary.readonly.appcreateddata
...photospicker.mediaitems.readonly		 Queries Google Photos items and albums matching the user's search term.
https://www.googleapis.com/auth/calendar.readonly Queries Google Calendar event summaries, dates, and descriptions matching the search term.
https://www.googleapis.com/auth/userinfo.profile
https://www.googleapis.com/auth/userinfo.email		 Retrieves the connected account's name, email, and profile avatar to display in the application header.

3. Where Data is Stored

  • OAuth Tokens: OAuth 2.0 access and refresh tokens are stored in the server session and persisted in backend/data/tokens.json on the hosting server instance to keep the user signed in.
  • User Notes: Notes created manually in the application interface are stored in backend/data/notes.json on the server instance.
  • Search Results: Search queries execute in real-time against Google APIs. Search results (email summaries, file titles, photos, event details) are returned directly to the active browser session in memory and are not stored in database files on the server.
  • Browser Storage: Browser localStorage is used on the client device to save UI theme preferences, export history, and connection state.

4. Third-Party Sharing

Digital Memory Vault does not include third-party advertising SDKs, tracking pixels, or third-party analytics scripts. Data retrieved via Google APIs is used strictly within the application interface to present search results and export user-requested reports.

5. Revocation & Data Disconnection

Users can disconnect their Google Account at any time by clicking "Disconnect Google Account" in the application profile menu. Disconnecting clears the server session, removes stored tokens from backend/data/tokens.json, and calls Google's token revocation endpoint.
